# Memory 模块

使用一个本机 SQLite 数据库，按逻辑分层，不建立四个独立数据库。

| 层 | 职责 | 当前代码 / 表 |
| --- | --- | --- |
| L1 原始资料 | 原文、分块、Embedding、来源定位 | `core/rag/`；`documents`、`document_chunks` |
| L2 世界事实 | 全文人物、事件、时间与关系，保留来源和审核状态 | `world.py`；`world_facts`、`document_graph_chunks` |
| L3 角色记忆 | 已知事件的引用，以及该角色如何记住它 | `builder.py`、`character.py`；`character_memories.world_fact_id`、`perspective` |
| L4 用户共同记忆 | 角色与用户的后续对话长期记忆 | `conversation.py`；原有 `memories`、会话与消息表 |

`graph.py` 定义结构化图数据及投影。API 编排留在 `apps/api/`，数据库模型按项目约定仍集中在 `infrastructure/database.py`。对话执行与上下文预算继续在 `core/chat/`。

## 当前实现边界

L2 的人物、事件、关系与文字时间暂以 `WorldFact.graph` 的结构化 JSON 保存，事实拥有稳定主键和来源片段。当前还不是分别规范化到 entities/events/relationships 的完整实体解析系统。同名人物按精确名称聚合，事件链接要求目标标题唯一；不会自动猜测别名，也不保证模型没有漏提。

L3 通过外键引用 L2，保存 `direct / witnessed / heard / inferred / unknown`、重要性、情绪、强度、关系变化及知情依据。Memory Builder 每批最多处理 20 条已审核的事实，生成草稿，未知跳过，已导入的引用不重复生成。情绪等是待审核的主观值，不会回写世界事实。

源事实改动后，关联的生效记忆退回草稿；源事实被拒绝、原文变动时，不参与角色检索。原文删除时外键置空，保留已生成的角色主观文字，不再能展开原事件。

L4 本轮保留既有对话记忆，不自动生成“情绪演化”“关系状态机”或虚构共同经历。这些应在有来源、可撤销的共同事件模型建立后再推进。

## 读取边界

聊天只召回当前角色生效且知情的记忆。引用事件的关联边只保留该角色已经获知的事件；不能为了补充因果而查询整部作品。世界文档不参加角色的自动全局 RAG，用户显式附上原文时可以讨论新提供的资料。

保留原有上下文预算，图谱大小不决定一次调用的输入大小。当前自动展开只包括受限摘要与关联，不承诺已实现任意深度的分层检索工具。

## 下一阶段顺序

已增加 `identity.py` 与按文档隔离的 `person_resolutions` 表：用户确认同一人/不同人，投影时应用别名，原始事实不改写。规则支持撤销、冲突与循环检查，并使已有角色引用重新进入审核。它不是完整的逐次提及实体消歧系统；同一简称指向多个人时仍需逐条编辑身份限定。

世界提取支持取消当前任务，保留完成片段，当前片段标为 `paused`；续跑跳过完成片段。取消不能撤回提供商已经处理或计费的请求。

1. 为事件建立独立实体 ID、别名审核和多来源证据，解决同名不同人与同一事件多次描述。
2. 在已知范围内增加按需事件详情工具，记录每次展开路径与 token 开销。
3. L4 增加双方共同事件和日期来源，再接角色关系变化；保留用户修改、停用与删除能力。
4. 用真实长文档评测覆盖率、身份混淆、时间顺序与“角色不应知道”的反例，而不是只看图是否漂亮。

## AI 自动整理（2026-09-21）

`organize.py` 在文档提取后逐段审核原文与事实；已有图谱使用“AI 整理已有图谱”，不需要重新上传。每批最多审核 8 条事实，并提供受上下文预算约束的其他事件候选。全文各批检查完成后才统一应用，避免先合并简称、后文才发现不同人的情况。

- 模型根据信息量筛选：纯时间过渡、装饰性语句可过滤；习惯、动机、关系变化和有意义的日常保留。`filtered` 是可恢复状态，原文与原始事实不删除。
- 人物规则只在明确原文依据、较高置信度且没有冲突时自动应用；人工规则优先。撤销自动规则后不会自动恢复该规则。
- 同一事件通过事实 ID 引用归组，展示时共用事件节点，保留不同来源事实。归并使用有限候选，不保证任意长文的所有重复事件均被识别。
- 整理进度与依据保存在 `graph_organizations`，SQLite 迁移 `sqlite_20260921_08` 自动建表。停止、异常与应用退出均可续跑已缓存的审核批次；过滤和合并不会只应用一半。
- 恢复并保留会将事实标为人工确认，后续自动筛选不覆盖；影响世界事实投影的变更使已有生效角色引用退回草稿。
- 整理会增加模型调用；模型自报的置信度不是准确率保证，未决歧义可查看依据并手动纠错。原文与事实更新会使旧整理结果过期。
