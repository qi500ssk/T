# MCP 服务器设置

在「设置与技能 → MCP 服务器」管理连接。自行配置的服务可编辑、删除、启停；插件提供的服务按来源分组，其密钥与开关在「插件」中管理。

## 新建与测试

新建或编辑页面提供表单和 JSON 两种方式，切换时保留当前配置。传输方式支持：

- **stdio**：启动本机命令，填写命令、参数和可选环境变量。参数每行一个，含空格的路径也放在同一行，无需额外引号。电脑需具备对应运行环境。
- **HTTP**：使用 Streamable HTTP，填写 MCP 地址与可选请求头。
- **SSE**：兼容采用 SSE 传输的服务，填写其 SSE 地址与可选请求头。

连接超时单位为毫秒，默认 30000，范围 1000–300000。该值用于建立连接、初始化和发现工具；工具执行仍受 Agent 的统一执行超时限制。协议版本由 MCP SDK 自动协商，作用域为本机用户。

「测试连接」实际启动命令或访问服务，成功后在当前页面显示工具列表。npx、uvx 等命令可能下载依赖。保存配置不会自动启用，需回到列表手动开启。

环境变量、请求头填写字符串键值 JSON。已保存的密钥不回显；编辑时留空保留原认证信息。更改远程地址、传输方式或本地启动命令及参数后，不自动复用旧认证信息。填写非空认证对象会替换原对象，应包含需要保留的全部键值。

## 导入 JSON

支持直接粘贴以服务名称为键的对象，或使用 `mcpServers` / `mcp_servers` 包装。每次可导入 1–50 个服务。所有服务先校验，再一起保存；同名冲突会拒绝整批导入，不覆盖已有配置。导入后均为关闭状态。

```json
{
  "mcpServers": {
    "my-local-server": {
      "type": "stdio",
      "command": "python",
      "args": ["-m", "scripts.mcp_demo_server"],
      "timeout_ms": 30000
    },
    "my-remote-server": {
      "type": "http",
      "url": "https://mcp.example.com/mcp",
      "headers": {"Authorization": "Bearer YOUR_API_KEY"}
    }
  }
}
```

`type: "http"` 对应内部 `transport: "streamable_http"`；也支持直接填写 `transport`。未填写类型时，有 URL 则按 HTTP 处理，否则按 stdio 处理。不支持的字段会报错，避免静默丢失配置。

「工具权限」可配置默认风险与允许的工具。JSON 中的 `tool_risk_levels` 可为单个工具设置风险，表单编辑会保留该规则。已连接的工具继续通过现有参数校验、审批和执行审计。
