# P5 阶段开发报告：主动工作

## 交付结果

P5 已完成 Activity 最小闭环。用户可以创建一次性或固定分钟间隔任务，在没有聊天 SSE 连接时由应用后台按时执行，并从 Activity 页面查看状态或进入专属会话查看完整结果。

执行链保持为：

```text
Activity（计划与状态）
  -> 单进程 Worker（领取到期记录）
  -> 现有 Agent Runtime
  -> Skill / Tool / MCP / Permission / ToolRun
  -> 专属 Conversation（用户提示词与助手结果）
```

没有引入 Redis、Celery、APScheduler、独立 Worker 进程或第二套 Agent 执行器。

## 后端

- 新增 `activities` 表，保存计划、状态、最近运行和错误；`agent_runs.activity_id` 关联每次实际执行。
- SQLite 兼容迁移可为已有 `agent_runs` 表补列和索引，并可重复执行。
- 支持 `once`、`interval` 两种调度；周期任务按原计划推进到一个未来时间，不补跑全部错过周期。
- 支持暂停、恢复、立即运行和删除；运行中活动禁止暂停、删除或重复领取。
- 启动时将遗留 `running` 恢复为 `scheduled`，采用 at-least-once 恢复语义。
- Worker 在 FastAPI lifespan 中、MCP 和 Provider 就绪后启动，关闭时先取消 Worker，再释放审批、MCP 与 Provider。
- `run_chat` 只增加可选的 `activity_id` 和 `approval_mode`，聊天默认行为不变。
- 后台遇到 high 风险工具时立即记录 rejected ToolRun，不创建审批 waiter，也不执行工具。
- Activity Run 跳过自动长期记忆提取，但保留原有摘要更新和 Context / RAG / Skill 能力。

## API 与前端

Activity API 提供列表、创建、详情、运行历史、暂停、恢复、立即运行和删除。创建时 Activity 与专属 Conversation 在同一事务中写入；仍被 Activity 引用的会话不能直接删除。

前端新增第四个“活动”主视图，包含：

- 一次 / 间隔模式创建表单；
- 浏览器本地时间到带时区 ISO 时间的转换；
- 状态、下次执行、最近完成和错误展示；
- 暂停、恢复、立即运行、查看会话和删除操作；
- 仅在活动视图挂载且页面可见时每 5 秒刷新。

## 配置与运行边界

```env
ACTIVITY_ENABLED=true
ACTIVITY_POLL_SECONDS=5
```

`ACTIVITY_ENABLED=false` 时 API 仍可管理计划，但不启动 Worker。轮询间隔限制为 1 到 60 秒。生产运行只允许单个 Uvicorn Worker；当前没有分布式抢占或 exactly-once 承诺。
