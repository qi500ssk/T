# 世界书工坊

在故事文档助手聊天中逐步确定需求，每次一个问题，ABCD 竖排选项占据输入区域，D 为自填。用户委托助手决定时不继续追问非必要偏好。

1. 助手询问篇幅、范围与资料，生成结构化创作方案。聊天中显示开始按钮，无需复制 JSON。
2. 后端先生成大纲与人物档案，确认大纲后分章写作；可停止并续写。
3. 自动保存到工作区的 `worldbooks` 子目录，聊天中显示实际保存路径、章节进度与字数。
4. 用户下载阅读并确认定稿后加入世界书。设置 → 世界书只保留上传入口和书架卡片，点击卡片可分页阅读全文，再选择书中人物创建独立角色。

每个人物使用稳定 ID，具有性格、动机、说话方式、关系、认知边界及对话示例。角色卡只包含该人物有依据知晓的事件视角和世界设定，不继承其他角色的聊天。实际正文字数仅统计事件正文，不统计 JSON 字段或重复的角色记忆。

默认目标为 12 章、每章至少 800 字。目标可以调整，篇幅达标不等于覆盖完整原作；检索资料只作为有界摘录，已有作品仍需用户检查来源与缺口。已有简短世界书不会被自动覆盖。

聊天不再额外调用模型生成内心独白；DeepSeek 请求明确关闭额外思考模式。数据库历史字段保留兼容，但聊天不再展示独白块。

设计参考：[SillyTavern World Info](https://docs.sillytavern.app/usage/core-concepts/worldinfo/)、[Character Design](https://docs.sillytavern.app/usage/core-concepts/characterdesign/)、[LongWriter](https://github.com/THUDM/LongWriter)。采用分条目存储和先规划再分章撰写，未引入第三方运行插件。
