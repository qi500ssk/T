# P3 阶段开发报告：开始做事

## 交付结果

P3 已完成最小本地工具执行闭环：模型通过 OpenAI 兼容 Tool Calling 请求工具，Agent 在后端校验白名单和参数，按固定风险等级执行或等待审批，将标准 `assistant.tool_calls + tool` 消息序列回传模型，并保存最终回答。

## 已实现能力

- `get_time`：查询本地日期、时间和时区；
- `calculate`：基于 AST 白名单计算表达式，限制语法、深度、指数和结果大小；
- `read_file`：读取沙箱内 UTF-8 文本，限制路径和字节数；
- `write_file`：固定 high 风险，每次写入都需要用户审批；
- `SKILL.md`：启动时加载启用 Skill，未声明工具不向模型暴露；
- Agent 多回合循环：流式拼接 tool call、顺序执行、累计 token usage；
- 单进程审批：批准、拒绝、超时、取消和应用关闭清理；
- `tool_runs`：记录调用 ID、顺序、风险、摘要、状态和耗时；
- 前端：工具状态、写入审批卡片、失效提示和移动端布局约束。

## 安全边界

- 文件工具只接受 `SANDBOX_DIR` 内相对路径；
- 拒绝路径逃逸、目录、符号链接和非 UTF-8 读取；
- 工具参数由后端再次校验，不信任模型生成的 JSON Schema 参数；
- 写入内容与工具结果有硬上限，数据库只保存截断摘要；
- `TOOLS_ENABLED=false` 时不传 tools、不注入 Skill 指令，保持 P2 行为。

## 当前限制

P3 的待审批状态只存在于单进程内存中，不支持服务重启恢复和多进程共享。动态风险、删除/移动文件、MCP、外部 API 和多用户权限不在本阶段范围内。
