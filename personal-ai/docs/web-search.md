# 联网搜索

入口：设置 → 联网搜索。聊天输入框不增加联网按钮。

1. 填写自己的 Tavily API Key，保存后仍保持当前开关状态。
2. 可先测试连接。测试发起一次基础搜索，可能消耗 Tavily 额度，但不会保存输入值或自动开启。
3. 开启「允许 AI 联网」。AI 根据问题选择搜索或读取网页；普通闲聊、改写已有内容和角色自身经历通常不需要搜索。
4. 关闭后撤销内置 `web_search`、`web_read` 工具；清除 Key 会同时关闭。已经发出的网络请求可能仍会完成。

后端直接通过 HTTPS 调用 Tavily，不需要额外安装本地命令运行环境。Key 保存在本机运行时设置的 `web_search` 区段；配置接口只返回是否已配置，不回显 Key。旧联网插件的 Key 自动迁移，迁移后默认关闭；第一次通过新入口保存或清除时移除旧插件中的 Key 副本。

搜索固定使用基础深度，最多返回 5 条结果；需要原文时每次读取一个公开网址。结果片段有长度上限，工具调用受现有 Agent 总超时和调用次数预算约束。聊天模型负责根据材料生成答案、给出来源；联网服务不额外生成最终回答。网页内容作为外部资料处理，不自动写入记忆或知识库。

关闭此设置仅控制软件内置联网工具。用户自行安装的其他网络工具有其各自的开关。

连接错误区分认证、额度、限流、超时和服务异常。当前版本不提供网站账号登录、浏览器操作、整站抓取或深度研究流程。

## 测试连接成功，但聊天失败

设置页测试的是 Tavily 搜索接口。聊天还需要先连接所选聊天模型，由模型决定是否调用搜索工具；模型连接失败时，即使 Tavily 正常也无法完成回答。

可在「过程」中查看失败原因和工具调用记录。若还没有搜索工具调用，优先检查聊天模型服务。模型网关在建立连接失败时会额外尝试一次直连，以处理系统代理链路不可用的情况；读取超时、流中断或已经收到响应的请求不会自动重放。

接口依据：[Tavily Search](https://docs.tavily.com/documentation/api-reference/endpoint/search)、[Tavily Extract](https://docs.tavily.com/documentation/api-reference/endpoint/extract)。
