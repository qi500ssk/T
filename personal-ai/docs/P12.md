# P12 个性化基础设置开发报告

## 结论

P12 已补齐个人助手最基础的三类用户配置：Agent 人格与自定义提示词、聊天模型选择与连接配置、Developer Tools 编码工作区文件夹选择。三类设置集中在“设置与技能”的基础设置分组，保存到被 Git 忽略的 `data/runtime-settings.json`，不再要求用户手工编辑项目代码。

## 使用方式

### Agent 设定

在“设置与技能 → Agent 设定”中可以修改：

- Agent 名称与扮演角色；
- 默认语言、语气、回答长度；
- 幽默程度、正式程度、主动程度；
- 最多 12000 字的自定义提示词。

可以把角色保存为多个带名称的预设，并选择一个当前使用的角色。自定义提示词非空时，它会完整覆盖名称、角色、语言、语气等基础 Prompt；自定义提示词为空时才使用基础设定。切换或保存当前角色后，后续对话和 Activity 会立即使用新配置，侧栏头像、名称和当前角色也会同步更新。

### 模型设置

当前提供四种配置入口：

- Mock：无需网络和 API Key；
- DeepSeek API：自动填写兼容地址和默认模型；
- Ollama：自动填写本地 OpenAI 兼容地址；
- 其他 OpenAI 兼容服务：手工填写 API 地址和模型名。

用户可以先“测试连接”，再“保存并应用”。保存时如有正在执行的对话或 Activity，系统会拒绝切换，避免中途关闭旧连接。API Key 不会通过 GET API 返回；输入框留空表示保留原 Key，也可以显式清除。

### 工作区选择

在“设置与技能 → 工作区”中可以手工输入绝对路径，也可以通过内置文件夹浏览器选择目录。保存后 `CODING_WORKSPACE_DIR` 立即更新，不需要重启后端。

选择文件夹不会自动开启 `Developer Tools` 插件。插件关闭时 Agent 仍不能访问代码；插件开启后，原有的敏感文件、依赖目录、符号链接、越界访问和高风险审批规则继续生效。

## 运行设计

```text
设置页
  → Settings API 参数校验
  → data/runtime-settings.json 原子写入
  → Agent Profile 原地更新 / Model Provider 安全替换 / Workspace 热更新
  → 后续 Chat 与 Activity 使用新配置
```

- 环境变量和 `.env` 仍是默认值，运行时设置只覆盖用户在界面保存的部分；
- JSON 使用同目录临时文件加 `os.replace` 原子写入；
- 损坏的 JSON 不会阻止后端启动，系统回退到环境默认值；
- 自定义 Prompt 只控制模型回答，不改变 Skill、Tool、MCP、审批和超时规则；
- 文件夹 API 只列出目录名称和路径，不读取或上传文件内容；
- 模型切换会重新创建 Provider 和 Activity Worker，旧 Provider 随后关闭；
- 后端关闭时恢复进程初始配置，下一次启动重新从本地设置加载。

## 主要文件

- `core/settings/runtime.py`：默认值合并、原子持久化与运行时应用；
- `apps/api/settings.py`：设置读取、保存、连接测试与目录浏览 API；
- `core/chat/character.py`：把用户配置安全合并进 Character；
- `prompts/system/main.md`：自定义指令插槽；
- `core/chat/agent.py`：Chat 与 Activity 注入 Agent Profile；
- `apps/web/components/GeneralSettingsView.tsx`：三类设置界面和文件夹选择器；
- `apps/web/components/SettingsSidebar.tsx`：基础设置导航；
- `tests/test_settings.py`：隐私、Prompt、模型热切换和目录选择测试。

## API

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/settings` | 返回脱敏后的当前设置 |
| PATCH | `/api/settings/agent` | 保存 Agent 人格与自定义提示词 |
| POST / PATCH / DELETE | `/api/settings/agents` | 创建、更新和删除角色预设 |
| PATCH | `/api/settings/agents/selection` | 切换当前使用的角色预设 |
| PATCH | `/api/settings/model` | 保存并热切换模型 |
| POST | `/api/settings/model/test` | 测试模型配置但不保存 |
| PATCH | `/api/settings/workspace` | 保存编码工作区 |
| GET | `/api/settings/directories?path=` | 浏览本机文件夹 |

## 当前边界

角色预设当前是本机全局选择，不会为每个对话单独绑定角色；模型协议目前统一走 OpenAI Chat Completions 兼容层，不支持各厂商独有参数。文件夹浏览面向本机单用户部署，不应将后端端口直接暴露到公网。后续可以增加会话级角色绑定、模型参数高级面板和人格配置导入导出。
